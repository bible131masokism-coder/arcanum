แนวทางอ่านโค้ด

เส้นทางแนะนำสำหรับทำความเข้าใจโครงการอย่างรวดเร็ว

เริ่มไล่จากจุดเริ่มแอป

  • index.html สร้าง host ของแอป แล้วโหลด src/index.js
  • src/index.js เตรียม Vue app และเรียก DataLoader.requestData()
  • src/dataLoader.js อ่าน data/modules.json แล้วโหลด core กับโมดูลที่ระบุ
  • src/game.js สร้าง/ควบคุมสถานะและ logic ระหว่างเล่น
  • src/ui/main.vue ประกอบหน้าจอจาก section และคอมโพเนนต์ย่อย

เพิ่มหรือแก้เนื้อหาเกม

เนื้อหาส่วนใหญ่เป็น JSON ใน data/ หากแยกเป็นโมดูล ให้ตรวจการลงทะเบียนไฟล์ใน data/modules.json และรูปแบบข้อมูลที่ src/modules/module.js รองรับ

ระบบข้อมูลจะรวม template เข้ากับข้อมูลเซฟ แล้วสร้าง instance/list สำหรับ runtime ดังนั้นควรตรวจทั้ง definition และโค้ดที่อ่านชนิดข้อมูลนั้น

พัฒนาและ build

  • npm install ติดตั้ง dependencies
  • npm run dev เปิด Vite dev server ที่พอร์ต 3000
  • npm run build สร้าง production output ใน dev/
  • npm run ci-dev รัน TypeScript compiler และ build

เซฟและการคงอยู่ของข้อมูล

การจัดการโปรไฟล์อยู่ใน src/modules/profile.js ส่วน persistence แยกเป็นตัวกลางและ backend ใน src/modules/persist/ README ระบุการใช้ IndexedDB พร้อม localStorage fallback และรองรับนำเข้า/ส่งออก JSON

คำเตือน: Vite ตั้งค่า emptyOutDir: true และ build ลง dev/ จึงล้าง output เดิมก่อนสร้างใหม่
สรุปจากโครงสร้าง repository และไฟล์ตั้งค่าที่มีอยู่ ณ เวลาจัดทำ · ไฟล์นี้เป็นเอกสาร HTML แบบ standalone ไม่มี dependency ภายนอก
